#  📊Customer Behavior Data Analytics Project

## 📌 Overview
This project demonstrates a complete end-to-end data analytics workflow, from data loading and cleaning to visualization and reporting. The analysis was performed using Python, SQL, and Power BI to extract meaningful insights and present them through an interactive dashboard and presentation.

---

## 📂 Dataset
The project uses a structured dataset containing records for analysis. The data was imported into Python, cleaned, and prepared before performing exploratory data analysis (EDA) and SQL queries.

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- PostgreSQL / MySQL / SQL Server
- Power BI
- Gamma (Presentation)
- Jupyter Notebook
- Microsoft Excel

---

## 🔄 Project Steps
1. Loaded the dataset into Python.
2. Performed data cleaning and preprocessing.
3. Conducted Exploratory Data Analysis (EDA).
4. Imported the cleaned data into SQL.
5. Executed SQL queries to answer business questions.
6. Built an interactive Power BI dashboard.
7. Prepared a detailed project report.
8. Created a presentation using Gamma.

---

## 📈 Dashboard
The Power BI dashboard provides interactive visualizations, including:
- Key Performance Indicators (KPIs)
- Trend Analysis
- Category-wise Insights
- Interactive Filters and Charts

---

## 📊 Results
- Cleaned and transformed the dataset for analysis.
- Identified key trends and patterns using EDA.
- Extracted business insights through SQL queries.
- Designed an interactive Power BI dashboard for decision-making.
- Summarized findings in a professional report and presentation.

---

## ▶️ How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook and run the analysis.
4. Import the SQL scripts into PostgreSQL/MySQL/SQL Server.
5. Open the Power BI (`.pbix`) file to explore the dashboard.
6. View the report and presentation for project insights.
